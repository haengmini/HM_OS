# HM OS v0.5.0 — Lofi Pixel Art Palette

사용자 피드백("lofi pixel art style 이거야!!")에 맞춰 마을 UI 전체를 밝은
파스텔 카툰 톤에서 **채도를 낮춘 따뜻한 로파이(lofi) 픽셀아트 톤**으로
다시 입힌 시각 릴리스. 공간·동선·기능은 변경하지 않았다.

## 변경 사항

- 전체 색상 팔레트를 고채도 파스텔에서 채도를 낮춘 황갈색·이끼색·황토색
  로파이 톤으로 교체 (`--village-*`, `--hm-os-*` CSS 변수 전면 갱신).
- 배경을 단색 그라데이션에서 저녁 노을풍 다단 그라데이션으로 변경.
- 맵 전체와 앱 셸에 SVG `feTurbulence` 기반 **필름 그레인 오버레이**를
  `mix-blend-mode: overlay`로 추가해 평면적인 벡터 느낌을 없앴다.
- 앱 셸에 은은한 **비네트**(가장자리 어둡게)를 추가해 아늑한 조명감을 줬다.
- 맵 오브젝트 아이콘에 `saturate(.85)` 필터를 적용해 이모지 글리프도 톤에
  맞게 절제된 느낌으로 통일했다.
- 잠금화면, 헤더, 내비게이션, 터미널/파일 패널, Hermes 대화창, 기기 선택
  모달까지 전체 UI 컬러를 동일한 로파이 팔레트로 통일했다.
- `prefers-reduced-motion`에서는 그레인/비네트를 포함한 장식 애니메이션이
  계속 억제된다(기존 규칙 유지, 신규 오버레이는 애초에 정적 이미지라
  영향 없음).

## 검증

- lint / typecheck / 전체 유닛 테스트(76+14+2) / 통합 테스트 / build 통과
- 실제 Chromium E2E 8개(desktop 1440×900, mobile 390×844) 통과
- npm audit: 0 vulnerabilities
- 실제 운영 tailnet HTTPS에서 데스크톱·모바일 로파이 화면을 시각 검증
  (그레인·비네트·저채도 톤·가독성 확인, 가로 overflow 없음)
