# HM OS v0.4.0 — Animal Crossing-style Village & Constant-speed Movement

두 가지 사용자 피드백에 대응한 릴리스.

## 이동 속도 버그 수정

- 이전에는 브라우저 네이티브 키 반복(길게 누르면 지연 후 빠르게 반복 입력되는 OS 동작)에
  그대로 의존해 캐릭터가 처음엔 느리다가 점점 가속되는 것처럼 보였다.
- 이제 키를 누르고 있는 방향을 `Set<Direction>`으로 직접 추적하고, 클릭 경로 이동과
  동일한 **고정 220ms 간격의 단일 게임 루프**가 한 틱에 정확히 한 칸만 이동시킨다.
- 키를 떼면 다음 틱부터 즉시 정지한다. 가속·감속이 없다.
- `ColonyMap.test.tsx`에 fake timer 기반 회귀 테스트를 추가해 모든 틱의 이동 거리가
  동일함을 검증한다.

## 동물의 숲 스타일 마을 컨셉

- 콜로니 맵을 어두운 SF 톤에서 **밝은 파스텔 아일랜드 마을**로 전면 개편했다.
- 구역: TOWN HALL(타운홀) · RESIDENT SERVICES(레지던트 서비스) ·
  MUSEUM(박물관) · NOOK'S CRANNY(너굴상점) · AIRPORT(공항)
- 맵을 가로지르는 강과 다리 한 곳만 건널 수 있는 지형을 추가했다(`RIVER_X`,
  `BRIDGE_Y_RANGE`).
- 나무·꽃·덤불 장식 타일과 흔들리는 애니메이션을 추가했다.
- 캐릭터를 각진 SF 실루엣에서 둥근 머리 + 귀 모양의 마을 주민 실루엣으로 교체했다.
- 잠금화면, 헤더, 내비게이션, 터미널/파일 패널, Hermes 대화창까지 전체 UI를 동일한
  파스텔 팔레트로 통일했다.
- 오래된 M3 방-카드 그리드 컴포넌트(`RoomPanel`, `AgentTile`, `roomLayout`)를
  제거했다 — M6 콜로니 맵으로 완전히 대체되어 더 이상 사용되지 않았다.
