# HM OS v0.3.0 — Colony Map & Device Colonists

RimWorld류 콜로니 시뮬레이션의 공간·동선 문법을 참고해 픽셀 오피스를 카드 그리드에서
**하나의 연속된 타일 맵**으로 전면 재구성한 기능 릴리스.

## 콜로니 맵

- 30×18 단일 연속 맵. 5개 구역(SYSTEM CORE / AGENT GUILD / KNOWLEDGE VAULT /
  QUEST STUDIO / CONTROL BAY)이 도로로 연결됨
- WASD·방향키 이동, 클릭 경로탐색(BFS), 모바일 방향 패드
- 서버 관제, 에이전트 현황판, 지식 보관소, 프로젝트 보드, 터미널, 파일 보관소,
  Hermes NPC를 실제 맵 오브젝트로 배치
- 근접 시 `E` 키 또는 화면 버튼으로 상호작용
- 실제 Agent OS 상태 이벤트가 맵 위 NPC 캐릭터 애니메이션으로 표현됨
  (working=타이핑, researching=발광, syncing=순찰, error=흔들림, offline=흑백)

## 기기 캐릭터 (Device Presence)

- 최초 접속 기기마다 `acer-nitro-windows` / `acer-nitro-linux` /
  `desktop-windows` / `iphone` 중 하나를 선택
- 선택은 해당 기기 로컬 저장소에만 저장되며 서버는 실시간 위치·온라인 상태만 관리
- 접속 중인 모든 기기가 맵 위에 각자의 캐릭터로 동시에 표시됨
- 현재 조작 중인 캐릭터에는 `YOU` 표시
- 상단 HUD의 `DEVICE 변경`으로 언제든 다시 선택 가능
- 새 인증된 API: `GET /api/devices`, `POST /api/devices/presence`

## Hermes NPC 대화

- 맵의 Hermes 캐릭터 또는 하단 독의 `Hermes` 버튼으로 실제 실행 중인 Hermes
  Agent와 대화
- SSE 스트리밍으로 실시간 응답, 진행 중 도구 사용 상태도 함께 표시
- 새 인증된 프록시 API: `POST /api/chat`, `GET /api/chat/history`
- Hermes API Server 자격 증명은 HM OS 백엔드 프로세스에만 로드되며 브라우저에
  노출되지 않음
- Hermes API 키가 구성되지 않은 배포에서는 대화 패널이 503으로 안내만 하고
  나머지 기능(맵·터미널·파일)은 그대로 동작

## 수정 사항

- 잠금화면 PIN 입력 필드에 명시적 `width: 100%`를 지정해, monospace + 넓은
  letter-spacing 조합에서 발생하던 실제 운영 HTTPS의 모바일 가로 overflow를
  제거
