# HM OS v0.2.0 — Pixel Office

HM OS의 주 화면을 실제 데이터 기반 탑다운 픽셀아트 Agent Operations HQ로 전면 개편한
기능 릴리스.

## 새 UI

- 연결된 하나의 오피스 floor plan
- 관제실 / 에이전트 길드 / 지식 도서관 / 프로젝트 공방 / 터미널 게이트
- CSS-only 픽셀 캐릭터(머리, 몸, 팔, 다리, 그림자, 개인 팔레트)
- 서버랙·홀로 테이블·책장·책상·소파·프로젝트 보드·터미널 포털 등 방별 가구
- 실제 `OfficeState` 기반 캐릭터 애니메이션
  - working/executing: 타이핑
  - researching: 연구 장비 glow
  - syncing: 걷기
  - error: shake
  - offline: grayscale
- 실제 event detail hover 말풍선
- entity/active/alert/sync 게임 HUD
- 터미널 게이트 오브젝트에서 실제 PTY와 파일 보관소로 직접 이동
- 하단 게임 app dock
- scanline, 야간 도시 배경, pixel tile floor

## 반응형·접근성

- desktop 12-column floor plan
- tablet 2-column map
- mobile 1-column vertical world
- 390×844에서 horizontal overflow 없음
- `prefers-reduced-motion` 지원
- 키보드 focus 표시 유지
- 실제 상태 텍스트와 ARIA navigation 유지

## 운영 품질

- Gowun Dodum과 Press Start 2P를 앱 번들에 포함해 외부 Google Fonts 요청 제거
- PWA offline shell에 폰트 포함
- 기존 인증·status WebSocket·PTY·파일·PWA 기능 보존
- desktop/mobile 실제 Chromium 렌더 및 E2E 검증
