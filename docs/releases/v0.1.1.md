# HM OS v0.1.1

설치 직후 바로 사용할 수 있도록 운영 안정성과 사용자 안내를 보강한 패치 릴리스.

## 변경 사항

- `docs/operations/QUICK_START.md`: Tailscale 확인 → URL 접속 → 최초 PIN → PWA 설치의
  3단계 사용 안내 추가
- `scripts/ensure-hm-os-running.sh`: PM2 daemon, HM OS API, userspace tailscaled,
  tailnet-only Tailscale Serve 상태를 자동 점검·복구
- Hermes script-only scheduler에 `hm-os-runtime-watchdog` 등록
  - 1분 간격
  - 정상 시 무출력·무알림
  - 복구 실패 시에만 알림
- 실제 운영 HTTPS 주소를 desktop 1440×900 및 mobile 390×844 Chromium에서 재검증
  - 첫 실행 `HM OS PIN 설정` 화면 정상
  - horizontal overflow 없음
  - manifest 연결 정상
  - service worker 등록 1개
  - console error 0개
