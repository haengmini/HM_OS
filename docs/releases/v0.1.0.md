# HM OS v0.1.0

첫 번째 서버 중심 개인 운영체제 릴리스.

## 주요 기능

- Tailscale 사용자 신원 + Argon2id PIN 기반 2단계 인증
- 자동 잠금, 세션 만료, 반복 로그인 rate limit
- 실제 Linux CPU/메모리/디스크 상태
- 실제 Agent OS 프로필 + Kanban 작업 상태
- 실제 Local Second Brain/Wiki 최근 문서
- 실제 프로젝트 최근 파일
- 실시간 WebSocket 상태 스트림
- 5개 방으로 구성된 반응형 2D 픽셀 오피스
- 브라우저 실제 PTY 터미널(node-pty, resize, Ctrl+C)
- 파일 탐색·읽기·편집·폴더 생성·이동·삭제·업로드·다운로드
- mtime 기반 동시 수정 충돌 감지(409)
- 경로 탈출 차단과 민감 내용 비기록 감사 로그
- Windows/모바일 대응 설치형 PWA 및 업데이트 배너
- PM2 기반 API/userspace Tailscale supervisor
- Tailscale Serve tailnet-only HTTPS
- GitHub Actions CI 및 태그 기반 release artifact

## 검증 결과

- lint/typecheck/build 통과
- 단위/통합 테스트 통과(실제 bash PTY 실행 포함)
- Playwright Chromium desktop 1440×900 + mobile Pixel 5 E2E 통과
- 인증→오피스→실제 PTY 연결→파일 편집/저장→PWA manifest/SW 흐름 통과
- 실제 tailnet-only HTTPS에서 app shell, manifest, SW, health, Tailscale 신원 검증 통과
- 직접 loopback 요청에서 Tailscale 신원 누락 시 403 확인
- npm audit high/critical 0

## 알려진 한계

1. 이 컨테이너에는 systemd가 없어 PM2를 사용한다. 프로세스 crash는 자동 복구하지만 컨테이너
   자체 재생성 후에는 호스트가 `npx pm2 resurrect`를 호출해야 한다.
2. userspace-networking Tailscale이므로 커널 TUN 인터페이스가 없다.
3. 앱 셸은 오프라인에서 열리지만 상태·터미널·파일은 서버 연결이 필요하다.
4. V1은 단일 소유자·단일 Linux 서버만 지원한다.
5. 파일 경로의 `..` 탈출은 차단하지만 root 내부 symlink가 root 외부를 가리키는 경우 실제
   경로까지 차단하는 realpath 기반 정책은 후속 보강 대상이다.
6. 이 서버에서 실제 Windows Chrome/Edge 설치 버튼을 직접 클릭할 수는 없어, 동일 엔진인
   Playwright Chromium desktop/mobile과 실제 PWA manifest/service-worker 배포로 자동 검증했다.
