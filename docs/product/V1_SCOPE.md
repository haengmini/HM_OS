# HM OS V1 Scope

> 정본 마일스톤 계획: `.hermes/plans/2026-09-19_140517-hm-os-v1.md`
> 이 문서는 그 계획에서 합의된 V1 범위를 제품 계약으로 고정한다.

## 목적

HM OS는 이형민의 서버 중심 개인 운영체제 인터페이스다. V1은 **현재 Linux 서버 한 대**의
실제 상태(시스템·Agent OS·Wiki/Obsidian·최근 문서)를 2D 픽셀 오피스로 시각화하고,
Tailscale 신원 + HM OS PIN으로 잠금 해제한 뒤 해당 서버의 터미널과 파일을 전면 제어할 수
있는 Windows 우선 PWA다.

## V1이 하는 것

- 2D 픽셀 오피스 홈 화면 (관제실 / 에이전트 작업실 / 도서관 / 프로젝트 룸 / 터미널 룸)
- 실제 서버 프로세스·디스크·메모리·서비스 상태 표시
- Agent OS 프로필과 작업 상태 표시
- 로컬 Wiki/Obsidian 및 최근 문서 표시
- Tailscale 사용자 신원 + HM OS PIN 2단계 인증과 자동 화면 잠금
- 잠금 해제 후 현재 서버에 대한 실제 PTY 터미널 제어
- 잠금 해제 후 현재 서버 파일 탐색·읽기·편집·생성·이동·업로드·다운로드
- Windows 데스크톱/노트북 우선 설치형 PWA, 모바일 반응형 상태 확인 및 잠금/해제
- Tailscale Serve를 통한 비공개 HTTPS 배포

## V1이 하지 않는 것

- Windows PC 등 원격 노드에 대한 명령 실행 (V1 이후)
- Three.js 기반 3D 오피스
- 다중 사용자 · 역할 기반 접근 제어
- 공개 인터넷 배포
- 새로운 sudo/root 권한 부여
- 사용자 승인 없는 자동 GitHub push, 태그, 배포
- 승인 없이 외부 서비스에 변경을 가하는 자율 루프
- 음성 대화, 복잡한 NPC 행동

## 권한 경계

- API·터미널·파일 작업은 현재 HM OS 서버 프로세스를 실행하는 Linux 사용자 권한을 넘지 않는다.
- 로그인(Tailscale 신원 + PIN) 이후 명령은 추가 확인 없이 즉시 실행한다.
- 화면 잠금/세션 만료 시 모든 PTY·파일 편집 채널이 즉시 차단된다.

## 종료 조건 (V1 Definition of Done)

- 두 대 이상의 개인 컴퓨터에서 Tailscale 비공개 주소로 설치·로그인·조회·터미널·파일 작업을
  실제로 수행할 수 있다.
- 인증 우회 테스트가 전부 실패한다 (401/403).
- 기존 연구 문서가 `docs/legacy/`에 원문 그대로 보존된다.
- lint / typecheck / unit / integration / e2e 테스트가 모두 통과한다.
- 사용자 승인 후에만 GitHub push 및 실제 배포가 이루어진다.
